# Ограниченная AppSec-проверка Telegram-адаптера — 18.09.2026

**Вердикт: PASS для локальной границы исходящего запроса.** Это не аудит
всего приложения, инфраструктуры Timeweb или Telegram.

Объект: пакет 0.4.0, `src/telegram.ts`, базовая main
`1cefab113fe5de5ff42274b7f8be5f75220caacd`. Проверка выполнялась
статически и локальными синтетическими HTTP-сценариями без настоящих секретов.

## Активы и границы доверия

- Токен бота даёт право писать от имени бота; его утечка критична.
- Текст сказки покидает приложение и передаётся Telegram — это ожидаемый поток.
- Ответ сети недоверенный: он не должен ложно подтвердить публикацию,
  вызвать повтор или неограниченное потребление памяти.
- `apiRoot` — только внутренняя тестовая зависимость. В будущей конфигурации
  её нельзя выставлять в переменные окружения или MCP-вход.

## Подтверждённые меры

- Production root разрешает только HTTPS `api.telegram.org`, без userinfo,
  query/fragment и нестандартного порта. HTTP допускается только для
  `127.0.0.1` с явным портом в тестах.
- Токен проходит ограниченную проверку и не может внедрить путь/query.
  Редиректы запрещены; независимый сервер назначения не получил запрос.
- В JSON находятся только `chat_id` и `text`; токена и `parse_mode` нет.
  В адаптере отсутствует логирование URL, токена, текста и тела ответа.
- Ответ ограничен 64 KiB по заголовку и фактическому потоку; лишнее тело
  отменяется. Невалидные UTF-8/JSON и неоднозначные ответы дают UNKNOWN.
- Таймаут охватывает заголовки и тело. 408/5xx/обрыв/редирект не вызывают
  автоматический повтор. Успех возможен только при HTTP 200, `ok=true`
  и безопасном положительном `message_id`.
- Проверка шаблонов секретов нашла только синтетический тестовый материал,
  собираемый из отдельных строк. Реальных токенов в репозитории нет.
  Зависимости не добавлялись; изменена только версия пакета и lockfile.

## Остаточные ограничения

- Bot API требует токен в URL. Будущие reverse proxy, APM и сетевые журналы
  должны редактировать или не сохранять исходящие URL; их конфигурация сейчас
  отсутствует и не проверялась.
- TLS/DNS и права настоящего бота не проверялись. До реального теста токен
  должен храниться только как секрет среды, а не в Git, образе или команде.
- Экспортируемый `apiRoot` безопасен только пока его задаёт доверенный код.
  Не подключать его к внешнему вводу. Для production использовать значение
  по умолчанию.
- Адаптер ещё не связан с MCP-аутентификацией и readiness-проверкой канала;
  этот PASS не распространяется на будущую интеграцию или деплой.
