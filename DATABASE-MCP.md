# База данных через YCS MCP

Две команды работают с существующей PostgreSQL из `DATABASE_URL`. Они доступны
только MCP-логину, заданному в `DASHBOARD_SNAPSHOT_MCP_CREDENTIAL_ID`, и только
в пределах прав пользователя БД. Новых переменных и миграций нет.

## Прочитать

`read_database` без аргументов перечисляет доступные таблицы. С `schema`
перечисляет таблицы этой схемы. Если добавить `table`, возвращает строки и
актуальный список полей, типов и первичный ключ. После добавления нового поля
оно появится при следующем вызове.

```json
{"name":"read_database","arguments":{}}
{"name":"read_database","arguments":{"schema":"dashboard","table":"projects","where":{"id":"project-1"}}}
```

Необязательные `columns`, `order_by`, `limit` и `offset` позволяют выбрать поля
и страницу. По умолчанию возвращаются все поля и до 50 строк (максимум 100).
`has_more` показывает наличие следующей страницы. Без первичного ключа или
`order_by` порядок строк между страницами не гарантирован.

## Записать

`write_database` получает схему, таблицу, действие и массив строк. Действия:
`insert` — добавить; `update` — изменить найденную строку; `upsert` — изменить
по первичному ключу или добавить, если строки нет. Все строки одной команды
записываются в одной транзакции.

```json
{"name":"write_database","arguments":{"schema":"dashboard","table":"projects","operation":"update","rows":[{"where":{"id":"project-1"},"values":{"title":"Новое название"}}]}}
```

`where` обязателен для `update` и `upsert`. Для `update` он должен выбрать ровно
одну строку; если намеренно меняются несколько одинаковых строк, задайте
`expected_count`. Для `upsert` в `where` нужен полный первичный ключ.
`insert` принимает `values`, в том числе `{}` для значений по умолчанию.
Другие строки и поля не меняются. Удаления строк, очистки таблицы, изменения
схемы и выполнения произвольного SQL нет.

Лимиты: до 100 строк записи за вызов, запрос до 64 КиБ, результат чтения до
1 МиБ. Прямая запись в таблицу снимка Dashboard обходит проверки специальной
команды `update_dashboard_snapshot`; для его обычных обновлений используйте её.
При потере ответа во время записи сначала перечитайте строки, прежде чем
повторять команду.
